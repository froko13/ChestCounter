# ChestCounter
Как запустить и добавить в OBS:
Запусти трекер: Дважды кликни по файлу start_tracker.bat (или выполни python app.py в терминале).
Добавь виджет в OBS:
В OBS в блоке Источники (Sources) нажми + → выбери Браузер (Browser).
В поле URL вставь: http://localhost:5050/widget
Укажи размер: Ширина 420, Высота 160.
Панель управления (по желанию): Открой в браузере http://localhost:5050/dashboard — там можно нажать кнопку «+1 Сундук (Тест анимации)», чтобы сразу увидеть, как виджет вспыхивает и подпрыгивает в OBS, а также поменять цель (GOAL).
Горячие клавиши прямо в игре:
На случай если ты захочешь вручную подправить счётчик или обнулить его перед новым стримом, работают кнопки:
F9 — прибавить +1 сундук (с анимацией)
F10 — убавить -1 сундук
F11 — сбросить счётчик текущей сессии в 0 (общий TOTAL при этом сохраняется в stats.json).
Важный совет для игры: чтобы скрипт видел экран игры, убедись, что в настройках видео Fortnite стоит режим «Оконный без рамки» (Windowed Fullscreen), либо в OBS/Windows захват экрана работает поверх игры. Если захочешь поменять дизайн виджета (цвета, шрифт, убрать/добавить строчки) — напиши, сразу подправим!
